# RTeam AI 基礎教育訓練

繁體中文 AI 工作地圖，以五大章節、22 個小章節呈現。一次閱讀一個主題，適合個人自學及現場培訓。

- 網站：https://ryan-tw-hans.github.io/RTeam_AISolution/
- 教材查核基準：2026-11-01（沿用原有教材日期，本次為版面與導覽改版）
- 章節：認識 AI、AI 工具地圖、AI 使用模式、工作應用與練習、風險與參考資料。

## 閱讀方式

從課程總目錄選擇大章節，再從章節目錄或左側目錄選擇小章節。每個小章節獨立顯示，底部提供上一頁／下一頁、頁次與位置進度；手機以「章節目錄」開合選單。內容區可在小螢幕或文字放大時單獨捲動，翻頁控制一直保留。

工具可按用途篩選，桌面每次最多顯示三項，手機每次一項，另有工具翻頁按鈕。工作示範保留四種模式切換，三題測驗保留即時解說、分數與重新練習。閱讀位置和已瀏覽頁數儲存在目前瀏覽器；未允許本機儲存時仍可正常使用。

網址的 `#小章節ID` 可直接分享，重新整理及瀏覽器上一頁／下一頁仍可定位。非互動控制項上可按鍵盤左右方向鍵翻頁；模式分頁本身則使用左右、Home、End 鍵切換。

## 維護

- `index.html`：閱讀器架構、網站資訊。
- `styles.css`：簡報版面、桌面與手機樣式、列印目前頁。
- `course.js`：章節、原有工具與教材、來源日期、情境示範和測驗資料。
- `app.js`：導覽、篩選、進度及互動。

不需要建置或外部套件，可直接開啟 `index.html`，或以 `python -m http.server 8765` 預覽。所有字型使用本機備援，不依賴外部 CDN。

保留 GitHub Pages 的 **Deploy from a branch → main → /(root)** 發布方式。提交到 main 後檢查 Pages 發布狀態及公開網站。

每次修改事實內容時，請另外確認官方來源網址、原始發布日期、查核日期，以及產品版本和授權可用性；版面更新不等同重新查核所有產品資訊。
